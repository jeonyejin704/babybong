      ☁️ 남편과 함께 관리 (클라우드 동기화)

      두 분이 같은 Firebase 설정과 같은 방 이름으로 접속하면 체크·예산·메모가 실시간으로 공유돼요. 최초 1회만 아래를 설정하면 됩니다. (Firebase는 구글의 무료 서비스, 카드 등록 불필요)

      1. console.firebase.google.com 접속 → 프로젝트 만들기
      2. 왼쪽 빌드 → Firestore Database → 데이터베이스 만들기 (위치 asia-northeast3 서울)
      3. 빌드 → Authentication → 시작하기 → 익명(Anonymous) 사용 설정
      4. 프로젝트 개요 옆 ⚙️ → 프로젝트 설정 → 내 앱 → 웹(</>) 추가 → 나오는 firebaseConfig 중괄호 { … } 부분을 복사해 아래에 붙여넣기
      5. 남편에게는 이 페이지 주소 + 같은 설정/방 이름만 알려주면 끝!
