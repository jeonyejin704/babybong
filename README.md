# 우리집 임신·출산 준비 대시보드 🤰👶

임신 5주차부터 출산·육아 준비까지, 엄마와 아빠가 **함께** 챙길 것을 한눈에 정리한 대시보드 초안입니다.

`index.html` 파일 하나로 동작합니다. 브라우저에서 열기만 하면 돼요. (설치·서버 불필요)

## 담긴 내용

| 섹션 | 무엇을 |
|------|--------|
| 📊 상태 스트립 | 마지막 생리 시작일(LMP) 입력 → **현재 주차 · 삼분기 · 출산 예정일 · D-Day** 자동 계산, 진행 바 |
| 💳 시기별 제도·혜택 | 초기/중기/후기/출산·육아 탭별 체크리스트 (바우처·부모급여·첫만남이용권·근로시간 단축·출생신고 기한 등) |
| 🩺 산전검사·예방접종 | NT·쿼드·정밀초음파·임당검사·GBS·Tdap 등 표준 일정 |
| 💊 영양제 가이드 | 시기별 엽산·철분·비타민D·칼슘·오메가3 |
| 🍽️ 먹거리 | 권장 음식 vs 조심할 음식(수은·카페인·리스테리아 등) |
| 💰 예산 가계부 | 항목별 예상/실제 지출 직접 입력 → 정부지원 차감한 **실질 순부담** 자동 계산 |
| 👩‍❤️‍👨 부부·아빠 체크리스트 | 진료 동행, 집안일 분담, 보험, 육아휴직 설계 등 |
| 📝 메모 | 진료 질문·결정 사항 자유 기록 |

## 특징

- **자동 저장**: 모든 체크·예산·메모·예정일은 브라우저(localStorage)에만 저장됩니다. 서버로 전송되지 않아요.
- **다크/라이트 테마** 지원, 모바일 반응형.
- 우측 상단 `↺ 초기화`로 전체 리셋 가능.

## ⚠️ 꼭 확인하세요

제도·지원금 **금액과 조건은 해마다·지자체마다 바뀝니다.** 이 대시보드의 숫자는 참고용 예시이며, 신청 전 아래에서 최신 기준을 확인하세요.

- 정부24 (gov.kr) · 복지로 (bokjiro.go.kr) · 아이사랑 · 관할 보건소/주민센터

건강 관련 결정은 반드시 담당 의료진과 상의하세요. 본 문서는 의료·법률·재정 자문이 아닙니다.

## 앞으로 개선하면 좋을 것 (아이디어)

- 지자체(거주지) 선택 시 해당 지역 출산지원금 자동 표시
- 주차가 되면 알림/강조되는 "이번 주 할 일"
- 예산 항목 추가/삭제, 카테고리 커스터마이즈
- 다태아·소득분위 선택에 따른 지원금 자동 반영
