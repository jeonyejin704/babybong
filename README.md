# 우리집 임신·출산 준비 대시보드 🤰👶

임신 5주차부터 출산·육아 준비까지, 엄마와 아빠가 **함께** 챙길 것을 한눈에 정리한 대시보드입니다.
`index.html` 파일 하나로 동작하고, **부부가 실시간으로 함께 관리**할 수 있습니다.

---

## 1. 웹페이지로 띄우기 (GitHub Pages · 무료)

주소만 누르면 열리는 웹페이지로 만드는 방법이에요.

1. GitHub 저장소 `jeonyejin704/babybong` 접속
2. 상단 **Settings** → 왼쪽 메뉴 **Pages**
3. **Build and deployment → Source: Deploy from a branch**
4. **Branch** 드롭다운에서 `claude/pregnancy-dashboard-draft-es7m4m` (또는 `main`) 선택, 폴더는 `/ (root)` → **Save**
5. 1~2분 뒤 새로고침하면 페이지 주소가 떠요 →
   **`https://jeonyejin704.github.io/babybong/`**

> GitHub Pages 무료 이용은 **공개(public) 저장소**에서 됩니다. 공개되는 건 이 템플릿 코드뿐이고,
> 실제 입력한 체크·예산·메모는 저장소에 들어가지 않아 남에게 보이지 않아요(아래 2번 참고).

### 남편도 편집자로 추가하려면
저장소 **Settings → Collaborators → Add people** 에서 남편 GitHub 계정을 초대하세요.
(단순히 페이지를 함께 *보고 쓰는* 것만이면 초대 없이 주소 공유만으로 충분합니다.)

## 2. 남편과 실시간으로 함께 관리하기 (클라우드 동기화 · 무료)

체크·예산·메모는 기본적으로 **각자 브라우저에만** 저장돼요. 두 분이 **같은 데이터**를
실시간으로 공유하려면 아래 Firebase(구글 무료 클라우드)를 **최초 1회** 설정하면 됩니다. 카드 등록 불필요.

### 최초 설정 (한 사람이 한 번만)
1. <https://console.firebase.google.com> 접속 → **프로젝트 만들기**
2. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3` 서울, 프로덕션/테스트 모드 무관)
3. 왼쪽 **빌드 → Authentication → 시작하기 → Sign-in method → 익명(Anonymous)** 사용 설정
4. **⚙️ 프로젝트 설정 → 내 앱 → 웹 앱(`</>`) 추가** → 표시되는 `firebaseConfig` 의 중괄호 `{ … }` 부분 복사
5. **Firestore → 규칙(Rules)** 을 아래로 바꾸고 게시:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /rooms/{room} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```
6. 대시보드 우측 상단 **☁️ 함께 관리** → 복사한 config 붙여넣기 + **방 이름**(둘만 아는 긴 암호처럼) 입력 → **연결**

### 남편은?
같은 페이지 주소를 열고, **같은 config + 같은 방 이름**을 한 번 입력하면 끝. 이후엔 한쪽이 체크·입력하면
상대 화면에 바로 반영됩니다. 설정은 각자 기기에 저장돼 다시 입력할 필요 없어요.

> **방 이름 = 우리 방의 열쇠**예요. `yejin-nampyeon-2027-baby`처럼 추측하기 어렵게 정하고 둘만 공유하세요.
> 우측 상단 상태 표시가 **"동기화 켜짐"** 이면 정상 작동 중입니다.
